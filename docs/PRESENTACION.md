# Presentación — 12 minutos

La exposición completa está repartida en cuatro documentos, duplicados en los dos
repositorios para que todo esté a mano en el stand:

| Documento | Para qué sirve |
| --- | --- |
| [`GUION.md`](GUION.md) | El guion minuto a minuto: qué se dice, cuándo y con qué diapositiva |
| [`DEMO.md`](DEMO.md) | Paso a paso de las tres demos en vivo y el plan B si el aula falla |
| [`Q-A.md`](Q-A.md) | Banco de preguntas del jurado: respuesta corta y respuesta completa |
| [`DIAPOSITIVAS.md`](DIAPOSITIVAS.md) | El contenido de las diapositivas |

Los dos proyectos:

- [`analizador-phishing`](../analizador-phishing) — detecta enlaces de phishing **sin
  visitarlos**.
- [`honeypot-casero`](../honeypot-casero) — registra lo que hace el atacante cuando entra.

**Narrativa central:** «Defendemos el phishing desde dos frentes: **antes del clic** y
**después del clic**».

**Regla de oro:** el público tiene que ver funcionando las dos herramientas; todo lo demás
es contexto. Si el tiempo aprieta, se recorta la explicación y **nunca** las demos.
